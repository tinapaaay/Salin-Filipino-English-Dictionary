# Salin

A Filipino word companion built to help users discover, search, and save meaningful Filipino words.

Salin is more than a simple translation dictionary. Each word includes a beginner-friendly meaning, pronunciation guide, example sentence, category, and related words.

## Features

- Search Filipino words and English meanings
- Filter words by category
- Word of the Day section
- Pronunciation guides
- Example sentences
- Related-word tags
- Save and remove favorite words
- Favorites stored with `localStorage`
- Responsive design for mobile and desktop
- Link to the KWF Diksiyonaryo for formal definitions

## Built With

- JavaScript

## Project Concept

Salin is designed as a modern Filipino word companion with a calm library-inspired visual style.

The app includes Filipino words about emotions, nature, values, and everyday life. It is a learning project with a small starter glossary, not a replacement for a formal dictionary.

## Reference

For detailed and formal Filipino definitions, visit the [KWF Diksiyonaryo ng Wikang Filipino](https://kwfdiksiyonaryo.ph/).

## Run locally

From the repository root, run `python3 -m http.server 5500`, then open [localhost:5500](http://localhost:5500). Python 3 is only a development-server option; VS Code Live Server also works. Stop the server with Ctrl+C. No package installation or build is required to serve this checkout.
